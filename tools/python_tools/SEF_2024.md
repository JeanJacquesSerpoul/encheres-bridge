# SEF 2024 — Conventions d'enchères

Ce document est la **description bridge** du système, pour la lecture. Il ne contient pas de règles exécutables :

| Fichier | Rôle |
|---|---|
| `cli/systems/sef/rules.yaml` | **Source unique des règles** (c'est lui que l'on modifie) |
| `SEF_2024_spec.md` | Sémantique des règles : séquences, conditions, algorithme de choix |
| `rules.json` | Règles expansées pour une application (généré) |
| `tests.json` | Cas de test de conformité (générés) |

Données issues des fiches <https://bridgesef.fr/>.

**Notation :** ♣ Trèfle, ♦ Carreau, ♥ Cœur, ♠ Pique. H = points d'honneur, HL = points d'honneur + longueur, HLD / DH = points de distribution, GH = gros honneur, FM = forcing de manche, NF = non forcing, BW = Blackwood.

## 1. Principes

Avec le moindre doute (surtout à 4), considérer l'enchère comme forcing.
Sans singleton ni fit majeur, on joue 3SA (sauf exceptions).

## 2. Ouvertures de 1♣ / 1♦

- **Ouverture :** mineure la plus longue, avec exceptions (beauté des couleurs, problème de redemande, désir d'entame).

### Réponses du répondant

| Enchère | Signification |
|---|---|
| 1♦ / 1♥ / 1♠ | 4 cartes minimum et 5+ H |
| 1SA | 6-10 HL, dénie une majeure 4e |
| 2SA | 11 HL, dénie une majeure 4e |
| 3SA | 12-15 HL, dénie une majeure 4e |
| 4SA | 19-20 HL, quantitatif |
| 2♣ / 2♦ (soutien) | Fitté, 6-9 HL |
| 3♣ / 3♦ (soutien) | Fitté, 10-11 HL |
| 1♣ – 2♦ ; 1♦ – 3♣ | 16+ HL et 6+ cartes : unicolore, proposition de chelem dans la couleur |
| 1♣/♦ – 2♥/♠ | 16+ HL et 6 cartes : proposition de chelem à ♥/♠ |
| 3♥ / 3♠ | Barrage, 7 cartes avec 2 GH |
| 4♣ / 4♦ | Barrage, 8 H maximum, NF |
| 1♣ – 4♦ ; 1♦ – 4♣ ; 1♣/♦ – 4/5 dans la couleur | Barrage |
| 4♥ / 4♠ | Naturel, 7 ou 8 cartes, semi-barrage, 10 H maximum |

### Séquence 1♦ – 2♣

- Deux seules séquences non forcing de manche : **1♦ – 2♣ ; 2♦ – 2SA** et **1♦ – 2♣ ; 2♦ – 3♣**.
- La redemande 2SA de l'ouvreur promet l'arrêt ♥/♠ (au minimum Valet troisième).
- Autres redemandes de l'ouvreur : 2♥/♠ = 3 ou 4 cartes (3♥/♠ : splinter à convenir) ; 3♣ = 5♦/4♣, 12-16 H ; 2SA = 12-14 ou 18-19 H ; 3SA = 15-17 HL, 4-4-4-1.

### Séquences spéciales à 4

- 1♦ P 2♣ 2♠ ; 2SA = 14/15 HL avec arrêt ♠.
- Intervention par X sur 1♦ – 2♣ : 2♦ naturel ; 3SA naturel ; 3♣ = 1 majeure 18-19 H ; 3♥/♠ naturel 15-17 H ; 4♣ = deux majeures 15-17 H ou plus, irrégulier ; 4♥ = deux majeures 18-19 H, régulier.
- Après une réponse à saut : 1♦ – 1♥ ; 2♣ – 2♠ ; 3♥ – 4♦ / 4♣ montrent le fit ♦ / ♣, 3♠ le fit ♥.

## 3. Ouvertures de 1♥ / 1♠

### Réponses du répondant

| Enchère | Signification |
|---|---|
| 1SA | 5-10 HL, non fitté |
| 2♥ / 2♠ (soutien) | Soutien simple ; l'ouvreur dispose de l'enchère d'essai généralisée |
| 2♣ / 2♦ | 4 cartes et plus, 11+ HL |
| 3♥ / 3♠ (soutien) | 11-12 DH, 4 atouts |
| 4♥ / 4♠ (soutien) | Barrage, 5 atouts |
| 2♠ sur 1♥ ; 3♥ sur 1♠ | 6 cartes, 16+ HL : proposition de chelem |
| 3♣ / 3♦ | 6 cartes, 16+ HL : unicolore, espoir de chelem |
| 3♠ sur 1♥ ; 4♣/♦/♥ sur 1♠ | Splinter |
| 4♣ / 4♦ | Splinter fitté : 4 atouts, 13-14 DH (maximum 10 H), singleton ♣/♦ |
| 2SA | 11-12 HL, fitté : 3 atouts ou 4 atouts et 4333 |
| 3SA | 12-14 H, 4 atouts |
| 4SA | Blackwood |
| 5♥ / 5♠ | Demande de qualité d'atout (Passe = 1 GH ; 5SA = A-R-D ; 6 dans la majeure = 2 GH) |

### Enchères d'essai après soutien simple

- **2SA** : essai généralisé, forcing de manche avec espoir de chelem.
- **2♠ (sur 1♥) ou 3♥ (sur 1♠)** : essai dans la majeure autre.
- **3♣ / 3♦** : essai à ♣/♦ (complément recherché pour la manche).
- **Essai dans la courte** : 3♣ / 3♦ = courte à ♣ / ♦ ; 3♥ sur 1♠ = courte ♠.
- Le mini revient à 3 dans la majeure ; le maxi dit 3SA ou 4♥/♠.
- Beaucoup de joueurs jouent NF la séquence 1♥ – 2♥ ; 2SA – 3♣ ; 3♥.

### Séquence 1♠ – 2♥

- 3♥ = 5♠ et 3♥, 14-19 HLD ; 4♣/♦ = splinter atténué, 4 atouts ; 4♥ = 5♠ et 4♥, 15-17 HLD ; 2♠ puis 2SA – 3♥ = 5♠ et 3♥, 12-13 HLD.
- Après 3♥, un 3♠ du répondant garantit le fit ♠.
- Deux séquences de compétition : 1♠ – 2♥ ; 2SA – 3SA ; 4♥ = fitté ♥ 18-19 sans GH ; 4♣/♦ = fitté ♥ 18-19 avec GH à ♥.

### 3SA et 4M fittés de l'ouvreur

- 1♣/♦ – 1♥/♠ ; **3SA** = 18-19 HL, 4432 ; **4♥/♠** = 18-19 HL, 5422 (significations inversables).

### Splinter de l'ouvreur et du répondant

- Voir §7 (Splinter).

## 4. Ouverture de 1SA

### Main d'ouverture

- Toutes mains régulières de **15-17 HL**.
- 5332 avec majeure 5e : **15-16 H**.
- Avec 4♥ et 4♠, on peut ouvrir 1♣/♦ à 15 H pour ne pas rater le fit majeur.

### Réponses à SA

| Enchère | Signification |
|---|---|
| Passe | Moins de 8 H |
| 2SA | 8 H, proposition de manche (quantitatif) |
| 3SA | 9-16 HL, contrat terminal |
| 4SA | 17 HL, quantitatif : invitation au petit chelem ; l'ouvreur dit 6SA avec 16-17 HL, passe avec 15 *(choix retenu ; la lecture « contrat terminal » n'est pas reprise)* |
| 5SA | 18-19 HL ; l'ouvreur repart en Baron ou dit 6SA |

### Stayman 2♣ — 4 réponses (avec chassé-croisé)

| Réponse de l'ouvreur | Signification |
|---|---|
| 2♦ | Pas de majeure |
| 2♥ | 4 cartes ♥ |
| 2♠ | 4 cartes ♠ |
| 2SA | 4 cartes ♥ ET 4 cartes ♠ |

- Après 2♦ : le répondant peut passer ou dire 2SA.
- Après 2♥ / 2♠ : passe ; ou une majeure au palier de 3 = **fit et espoir de chelem** (1SA – 2♣ ; 2♥ – 3♠ ; 2♠ – 3♥, avec ou sans contrôle) ; ou 4♣ / 4♦ = **splinter fitté**, environ 13-14 H.
- Après 1SA – 2♣ ; 2♠ : 2SA puis 3♥ de l'ouvreur = 3 cartes ♥ et maxi, au cas où le répondant aurait 5♥.
- Après 2SA (deux majeures) : 3♣ relais pour 3♥, NF de manche ; 3♦ relais pour 3♠, NF de manche ; 4♣ Texas pour 4♥, NF ; 4♦ Texas pour 4♠, NF ; 3♥ / 3♠ naturel, forcing de manche avec espoir de chelem.
- Stayman avec main 4333 : à partir de 12 H sur 1SA (8 H sur 2SA), d'après Guy Lasserre.
- **Misère dorée** : Stayman avec une majeure 5e et un singleton, ou une main de 7-8 HL.

### Texas (transferts)

| Enchère du répondant | Texas pour | Réaction de l'ouvreur |
|---|---|---|
| 2♦ | ♥ | Rectifie à 2♥ |
| 2♥ | ♠ | Rectifie à 2♠ |
| 2♠ | ♣ | Rectifie à 3♣ (ou module avec un GH troisième) |
| 3♣ | ♦ | Rectifie à 3♦ (ou module avec un GH troisième) |

- Après Texas majeur : l'ouvreur peut sauter à 3♥/♠ s'il est maxi avec 4 atouts.
- Après Texas mineur (1SA – 2♠ ; 3♣) : le répondant nomme sa courte : 3♥ = courte ♥ ; 3♠ = courte ♠ ; 3SA = courte dans l'autre mineure. Suites : 4♣ = 6♣ sans singleton ; 4♦ = 6♣ et singleton ♦.
- Après 1SA – 3♣ ; 3♦ : 4♣ = 6♦ et courte ♣ (chelem ♦) ; 4♦ = 6♦ sans courte ; 4SA = quantitatif 16-17 HL ; 5SA = quantitatif avec 5 cartes, 18 HL+.

### Bicolores majeurs

| Main | Enchère recommandée |
|---|---|
| 5♥/5♠ faible | Texas ♠ (ou Texas ♥ puis 2♠) |
| 5♥/5♠, 7-8 H | Texas ♥ puis 2♠ |
| 5♥/5♠, 9-12 H | **4♦** |
| 5♥/5♠, 13-14 H | Texas ♠ puis 4♥ |
| 5♥/5♠, 15+ H | Texas ♠ puis 3♥ |
| 5♥/4♠ ou 5♠/4♥ faible | Texas pour la plus longue |
| 5♥/4♠ ou 5♠/4♥, 7-8 H | Stayman, puis nommer la majeure sur 2♦ ou soutenir la majeure répondue |
| 5♥/4♠ ou 5♠/4♥, 9+ H | Stayman, puis majeure à saut en chassé-croisé |
| Majeure 6e / 4e, faible | Texas |
| Majeure 6e / 4e, moyen | Texas ou Stayman suivi de 4♥/♠, ou Stayman suivi d'un chassé-croisé au niveau de 3 |
| Bicolore mineur 5/5 de manche ou plus | Texas pour ♣, puis annoncer ♦ |

### Autres enchères directes

- **3♦ / 3♥ / 3♠** : espoir de chelem dans la couleur.
- **3♣** : Texas ♦ (voir plus haut).
- **4♥ / 4♠** : naturel, 5+ cartes, contrat terminal.
- **4♦** : bicolore ♥/♠.
- **4♣ : n'existe pas en SEF** (Gerber et les bicolores en 4♣ sont des options non SEF).

## 5. Ouvertures de 2♣, 2♦, 2♥/2♠, 2SA

### 2♣ — fort indéterminé

- Artificiel, auto-forcing mais pas forcing de manche. Le répondant relaie **2♦** (obligatoire), puis l'ouvreur décrit sa main.
- Ouvertures de 2 en mineure : 7 cartes ♣/♦ avec minimum 15 H.

| Redemande de l'ouvreur après 2♣ – 2♦ | Signification |
|---|---|
| 2♥ / 2♠ | Soit 6 cartes et 8-8½ levées de jeu, dont au moins 2 levées de défense ; soit 5 cartes et 21-23 HL (main 5-4 possible) |
| 2SA | 22-23 HL, main (semi-)régulière, majeure 5e possible |
| 3♣ / 3♦ / 3♥ / 3♠ | 7 très belles cartes : 8-8½ levées de jeu en majeure, 8½-9½ en mineure |
| 3SA | 5♠-5♥, bicolore de 3 perdantes |
| 4♣ | 6♥-5♠, bicolore de 3 perdantes |
| 4♦ | 6♠-5♥, bicolore de 3 perdantes |

Le répondant peut alors passer ou poursuivre :

- **Sur 2♥ / 2♠** : 2SA = forcing, 5+ H ; nouvelle couleur au palier de 3 = 5 cartes correctes et 7+ H ; soutien au palier de 3 = espoir de chelem ; couleur à saut = **splinter** (singleton ou chicane, 4+ atouts, un contrôle d'honneur au plus, atout compris) ; saut à la manche dans la couleur de l'ouvreur = conclusion.
- **Sur 2SA** : comme sur l'ouverture de 2SA, en décalant les zones d'un point vers le bas.
- **Sur 3♣ / 3♦** : une nouvelle couleur au palier de 3 montre une force dans la couleur, pas forcément une longueur ; le fit au palier de 4 montre un espoir de chelem.
- **Sur 3♥ / 3♠** : une nouvelle couleur montre un contrôle avec un fit implicite ; le fit au palier de 4 est une conclusion.
- **Sur 3SA / 4♣ / 4♦** : le répondant choisit la majeure à 4.
- **Après la redemande 2SA de l'ouvreur** : il est conseillé de toujours faire un Stayman avec une main 4333 comprenant une majeure 4e, car l'ouvreur est souvent 5431 ou 5422.
- **Zones de points (choix retenu) :** 2SA d'ouverture = 20-21 HL régulier ; avec plus fort, ouvrir 2♣ puis redemander 2SA (après 2♦) = 22-23 HL. La phrase de la fiche 2♣ sur le 6-3-2-2 mineur (« 20-21 H : ouvrir 2♣ suivi de 2SA ») contredit ces zones et n'est pas reprise.

### 2♦

- Ouverture SEF (fiche) : **forcing de manche**, 9 levées de jeu plus 2 levées de défense annexes. *(Choix retenu : 2♦ fort avec demande d'As, conformément à la fiche ; les variantes faible, multi et Flannery sont non SEF.)*

| Réponse du partenaire (demande d'As) | Signification |
|---|---|
| 2♥ | Pas d'As |
| 2♠ | Un As majeur |
| 2SA | 8+ H, main régulière |
| 3♣ / 3♦ | As de ♣ / ♦ |
| 3♥ | 2 As de même couleur |
| 3♠ | 2 As de même rang |
| 3SA | 2 As mélangés (♠/♦ ou ♥/♣) |
| 4 dans une couleur | 3 As (sauf celui de la couleur citée au niveau 4) |
| 4SA | 4 As |

- Sur 2♦ – 3♦ : 3SA = 24-25 H (Stayman et Texas possibles) ; 4SA = 26-27 H (forcing un tour, Stayman et Texas) ; 5SA = 28 H (forcing un tour, Baron).
- Sur 2♦ – 2♥ : 3SA = arrêt ; 4SA = Blackwood ; 4♣ = BW aux Rois (optionnel) ; 3♥ = 5-6♥ sans 4♠ ; 3♠ = 5-6♥ avec 4♠ ; 4♠/5♣/5♦/5♥ = fit et chicane.
- Sur 2♦ – 2♠ : 4♣ = interrogatif à l'As majeur.
- Sur 2♦ – 3♣/3♦ : 4SA = BW aux Rois.
- Sur 2♦ – 3♥ ou 3♠ : le 3SA de l'ouvreur est forcing ; son 4SA est un BW aux Rois.
- Sur 2♦ – 3SA (2 As) : le 4SA de l'ouvreur est naturel et forcing.
- Sur 2♦ – 2SA ; 3SA ; 4SA = quantitatif (Baron facultatif) ; 2♦ – 2SA ; 5SA = Baron obligatoire.
- Si réponse en As, un BW ultérieur demande les Rois.

### 2♥ / 2♠ — faible

- **6 cartes minimum, 6-10 H** (points d'honneur ; vulnérable : 7-10 H et 2 gros honneurs ; vulnérabilité favorable : 5-10 H).
- Réponses : changement de couleur = forcing, 15+ HLD ; soutien = barrage, positif ou non ; **2SA relais** avec espoir de manche.
- Après 2SA : 3♣/♦/♥ = As ou Roi dans la couleur ; 3SA = maxi sans force annexe ; 4♣/♦/♥ = maxi avec singleton ou chicane. Sur 2♥ – 2SA ; 4♥ = courte ♠.
- Changements de couleur naturels : 3♣/♦ = forcing ; 4♣/♦ = bicolore de rencontre avec fit 4e ; 5♥/♠ = barrage ; 2♠ – 4♣/♦/♥ = rencontre.
- Blackwood sur 2 faible (fiche « 4SA / BW ») : voir §11.

### 2SA

- **20-21 HL**, main régulière. Peut comporter une majeure 5e, ou être 5422 ou 6322 avec 6 cartes en mineure.
- **Stayman 3♣ (4 réponses, comme sur 1SA)** : 3♦ = pas de majeure 4e ; 3♥ = 4 cartes ♥ ; 3♠ = 4 cartes ♠ ; **3SA = les deux majeures 4es**, avec relais du répondant 4♣ pour ♥, 4♦ pour ♠. *(Choix retenu ; le Puppet Stayman, cité par la fiche comme convention alternative, n'est pas SEF.)*
- **Texas majeur** : 3♦ pour ♥ ; 3♥ pour ♠. L'ouvreur rectifie s'il est fitté avec un gros honneur ; sinon 3SA. Après rectification : 4♣/♦ = contrôle, intérêt de chelem.
- **Pas de Texas mineur sur 2SA** : 3♠ et 4♣ ne sont pas définis. *(Choix retenu : la fiche range les Texas mineurs sur 2SA parmi les options non SEF. Sur 1SA, les Texas mineurs 2♠ et 3♣ restent SEF, voir §4.)*
- **4♣ : pas de Gerber, enchère non définie** (comme sur 1SA, où « 4♣ n'existe pas en SEF »). *(Choix retenu.)* Le 4SA reste quantitatif.
- **4SA** : quantitatif (16-17 HL estimé) ; **5SA** : invitation à 6SA.

|---|---|

| 3SA | Naturel |

### 3SA

- SEF : mineure 7e affranchie et rien à côté.
- Réponses : 4♣ = pour jouer 4♣/♦ ; 4♦ = pour jouer 6♣/6♦ ; 4♥/♠ = naturel ; 4SA = Blackwood ; 5♣ = pour jouer 5♣/♦.
- Interrogatif au singleton (4♦) : 4♥/♠ = singleton ♥/♠ ; 4SA = pas de singleton ; 5♣ = singleton ♦ ; 5♦ = singleton ♣.

### 4♣ / 4♦ / 4♥ / 4♠

- SEF : barrage à 8 cartes dont 2 gros honneurs, ou main 7/4.
- 4♣/♦ → 4♥/♠ : naturel ; 4♣ → 4♦ : naturel ou contrôle avec fit ♣ ; 4♥ → 4♠ : à préciser si naturel pour les jouer ; 4♥/♠ → 4SA : Blackwood ; 5♣ / 5♦ : contrôle ; 5♥/♠ : demande de qualité d'atout.

### 4SA

- SEF : bicolore de mineures 6/5+ et 4 perdantes. Réponses : 5♣/♦ = préférence ; 5SA = choix pour 6♣/♦.

### 5♣ / 5♦

- SEF : 9 cartes barrage ou 8/4 en mineures.

### 5♥ / 5♠ et 5SA

- Non définis en SEF : la fiche ne les décrit que comme options non SEF, non reprises ici. *(Choix retenu.)*

## 7. Conventions à 2 (camp de l'ouvreur, sans intervention)

Fiche : « SEF Les Conventions à 2 ».

### Auto fragment-bid

- Soutien de l'ouvreur valant 20-22 HLD, fit 4e et 6 belles cartes à ♣/♦ (1♣ – 1♥/♠ ; 4♣ ; 1♦ – 1♥/♠ ; 4♦).

### Bicolore cher de l'ouvreur

- 17+ H (16 H pour un bicolore régulier à points concentrés). Sur 1SA : forcing de manche avec 19+ HL.
- 1♣ – 1♠ ; 2♥ – 2SA ; 3♥ = NF ; 3♣ = NF mais 3♠ FM. 1♣ – 1♠ ; 2♥ – 3♠ = FM (6 beaux ♠ : envie de chelem). 3♣ = GH 3e ♣ ou 4 cartes ♣ ; 4♣ = chelem ♣ ; 3♦ = 4e couleur, dénie 5♠.

### Blackwood et enchères de 5

- Voir §11.

### Check-back Stayman

- **SEF 2024** : la fiche préconise de **ne pas sauter à 2SA si l'on possède une majeure 4e**. Il n'y a donc pas de check-back Stayman en SEF 2024 ; beaucoup de joueurs jouent néanmoins le SEF 2018, où la convention existait.
- **Check-back Stayman SEF 2018 — ajouté à votre demande, à jouer par accord de paire** : après une redemande de l'ouvreur à 2SA **avec saut** sur la réponse de 1♥/♠, la nomination de **l'autre mineure** (celle qui n'a pas été ouverte) est conventionnelle : elle demande à l'ouvreur son nombre de ♥ et de ♠.

**Séquences du check-back SEF 2018 (lecture à confirmer)**

| Séquence | Réponse | Signification |
|---|---|---|
| 1♦ – 1♠ ; 2SA – **3♣** (check-back) | 3♦ | 5 cartes à ♦, ou espoir de chelem |
| | 3♥ | 4♥ et peut-être 3♠ |
| | 3♠ | 3♠ sans 4♥ |
| | 3SA | Ni 3♠ ni 4♥ |
| 1♣ – 1♠ ; 2SA – 3♣ | | Naturel, fitté avec courte annexe (ici 3♣ n'est pas un check-back : ♣ est la mineure ouverte) |
| 1♣ – 1♠ ; 2SA – 3♥ | | Espoir de chelem avec 5♠ et 5♥ |
| 1♦ – 1♥ ; 2SA – 4♥ | | Pour jouer 4♥ *(précisé par vous)* |
| 1♦ – 1♠ ; 2SA – 4♠ | | Pour jouer 4♠ *(précisé par vous ; la fiche imprime 4♥ / « 4♥ ou 4♠ »)* |

- Les réponses 3♦ / 3♥ / 3♠ / 3SA sont les quatre échelons de réponse de l'ouvreur au check-back 3♣ (la mise en page de la fiche les présente en colonnes, ce qui a pu m'induire en erreur dans une lecture précédente).
- Les enchères de 4♥ et 4♠ sont des signoffs naturels : 4♥ pour jouer 4♥, 4♠ pour jouer 4♠.

### Drury

- Après passe, le soutien du répondant change : **2♣ = Drury**, soutien 3 atouts (ou 4 sans singleton), 11-12 HLD.
- **Drury simple** : 2♦ ambigu, espoir de manche ; 2♥ = 5/4 avec ouverture ; 2♠ = 5/6 cartes pour s'arrêter ; 2SA = 15-17 H ; 3♣ = 16+ HL ; 3♦ = 5/5, 16+ ; 3♥ = 5/5, 16+ ; 3♠ = enchère de chelem ; 3SA = 17-19 H.
- **Super Drury** : 2SA = 11 HLD, 4 atouts, 1 singleton ; 3♣ = interrogatif au singleton ; 3♦ / 3♥ / 3♠ / … = singleton (sur 1♠ : 3♦ = ♦, 3♥ = ♥, 3♠ = ♣ ; sur 1♥ : 3♦ = ♦, 3♥ = ♣, 3♠ = ♠).

### Enchère d'essai

- Après soutien simple : 2SA = essai généralisé manche/chelem ; 3♣/♦ = essai de manche dans la couleur, demandant de l'aide ; 3♥ (sur 1♠) = essai pour 4♥/♠ ou plus ; 4♥ = 5/5, meilleure manche si partenaire 4♥.
- Réponses du répondant : 3SA = main 4333 ; 3♣/♦ = force ♣/♦ ; 4♣/♦ = courte ♣/♦.
- Après soutien mineur (1♣ – 2♣) : 2♦/♥/♠ = force dans la couleur pour 3SA ; 2SA = essai généralisé ; 3♣ = barrage.

### Enchères impossibles

- Après 1SA : le répondant montre un énorme fit fort dans la 2e couleur de l'ouvreur (ex. 1♥ – 1SA ; 2♣ – 2♠ = force ♠ ; 3♦ = force ♦ ; 3♥ = honneur second ♥ avec 5♣).

### Problème des ♦ et des ♥

- Retour à la majeure du partenaire = double signification : fitté, ou pas d'arrêt (ex. 1♦ – 1♥ ; 1SA – 3♦ ; 3♥ = pas d'arrêt ♠).

### Rencontre

## 10. Contres, surcontres, cue-bids

## 11. Forcing / non-forcing, Blackwood, 4SA et 5SA

### Forcing / non-forcing

- Test de 46 séquences (réponses : forcing, forcing de manche, non forcing, appel, à convenir), et commentaires de joueurs de haut niveau. Conseil constant : « mettez-vous d'accord avec votre partenaire ! ».
- Exemples de réponses de la fiche : 1SA P 2♦ 2♠ = non forcing ; 1♣ P 1♥ 2♦ ; 2♠ = forcing de manche ; 1♣ 1♠ X P 2♦ = forcing ; 1♥ 2♦ X P 3♣ = non forcing ; 1♦ 2♣ ; 2SA ; 3♣ = forcing de manche ; 1♦ 1♥ 1SA 2♣ = forcing, enchère de chelem.
- Après 2SA limite du répondant au 2e tour : selon Lévy et les Bessis, la répétition de la 1re couleur du bicolore est forcing, celle de la 2e non forcing ; selon Soulet, tout est non forcing sauf l'annonce de la 4e couleur.
- Processus forcing de manche : quand personne n'arrête ♣ ou ♦ à 4 (1♦ 2♣ ; 2♦ 3♦ ; 3♣ 4♦), la séquence est forcing de manche.

### Blackwood 5 clés (SEF)

| Réponse à 4SA | Signification |
|---|---|
| 5♣ | 3 ou 0 clé |
| 5♦ | 4 ou 1 clé |
| 5♥ | 2 clés sans la Dame d'atout |
| 5♠ | 2 clés avec la Dame d'atout |
| 5SA | 2 clés ou 4 et 1 chicane |
| 6♣ | 3 ou 1 clé + 1 chicane ♣ |
| 6♦ | 3 ou 1 clé + 1 chicane ♦ |

- Après une réponse d'un As (5♦), la « collante » (couleur d'atout immédiatement au-dessus) demande la Dame d'atout. Réponses : pas de Dame = 5♠ (sur 5♥) ; avec la Dame, nommer le Roi annexe (6♣ Roi ♣, 6♦ Roi ♦, 6♥ Roi ♥) ou 6♠ = Dame d'atout sans Roi annexe. Avec 1 ou 2 atouts de plus que prévu, répondre la Dame même si on ne l'a pas.
- Nombre de clés pour poser un BW (jeu 30/41, sauf exception) : ♣ = 3 clés ; ♦ = 2 clés ; ♥ = 2 clés ou 1 + Dame d'atout (5♠ empêche de jouer 5♥) ; ♠ = 0 clé.
- **BW aux Rois à 5SA** : proposition de grand chelem après une réponse au BW ; répondre 7 si 13 levées sont comptées, sinon nommer la couleur de ses Rois par ordre économique ; on continue si le grand chelem est envisageable.
- **5SA après BW** = demande de Rois ou grand chelem. Sans BW, avec saut : **Joséphine** (demande de nommer le grand chelem avec 2 GH d'atout).
- **5 dans une majeure commune** = demande de qualité d'atout si l'enchère précédente ne dépasse pas la manche (sauf enchère forcée), sinon demande du contrôle manquant. Réponses : petit chelem avec 2 GH, passe avec 1 GH, 5SA avec A-R-D.

### 4SA : Blackwood ou quantitatif ?

- **Règle 1** : 4SA est BW quand un soutien a été exprimé ou clairement sous-entendu, ou quand le répondant n'a pas la place d'exprimer ses velléités de chelem.
- **Règle 2** : 4SA n'est jamais quantitatif sur des enchères majeures exprimées au palier de 3 et 4 (1♠ 2♣ 3♠ 4SA = BW ♠).
- **Règle 3** : 4SA est quantitatif quand il suit directement une enchère à SA (1SA 4SA ; 2SA 4SA).
- **Règle 4** : 4SA est quantitatif s'il n'y a pas de fit implicite ou explicite (1♥ 1♠ ; 2♥ 4SA quantitatif ; 1♣/♦ 4SA quantitatif dans le SEF).
- Sur un quantitatif, on peut selon la séquence nommer une couleur 4e au niveau de 5, une couleur 5e au niveau de 6, ou dire ses As.
- Autres 4SA : décourageant (1♦ 3SA 4♣ 4SA), compétitif (1♦ 1♠ 3SA 4♠ 4SA), naturel (double fit).
- **5SA** : « choisis ton petit chelem » après fit (proposition de grand chelem) ; 5SA direct sur 1SA/2SA n'est pas un BW mais une proposition quantitative de grand chelem.

### Blackwood sur 2 faible et sur barrage

- **BW sur 2 faible (Lebel)** : 2♠ 4SA ; 5♣ = ni l'As ni le Roi d'atout ; 5♦ = As ou Roi d'atout ; 5♥ = As-Dame ou Roi-Dame d'atout ; 5♠ = As et Roi d'atout ; 5SA = A-R-D d'atout.
- **BW sur barrage** : 4♠ 4SA ; 5♣ = 0 As ; 5♦ = 1 As sans Roi ni Dame d'atout ; 5♥ = 1 As + Roi ou Dame ; 5♠ = 1 As + Roi + Dame d'atout ; 5SA = As ♣.
